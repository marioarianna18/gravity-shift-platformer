# Gravity Shift 🤖

A simple 2D platformer prototype built with **Godot 4** and **GDScript**, created primarily to practice and experiment with the engine's physics, custom gravity-inversion mechanics, and procedural level generation.

## 🚀 Features & Mechanics
* **Gravity Inversion:** Press the `SPACEBAR` to flip gravity and walk on ceilings or platforms upside down.
* **Procedural Setup:** Level layout, obstacles, and hazard zones generated cleanly through GDScript.
* **Death & Respawn:** Falling into gaps or touching the red ceiling/floor resets the player to the spawn point.
* **Victory Condition:** Reach the green zone at the end of the course to trigger the "LEVEL COMPLETED!" screen.

## 🛠️ Built With
* **Engine:** Godot 4 (GDScript)
* **Concept:** Personal practice project for learning 2D movement logic and collision handling.
